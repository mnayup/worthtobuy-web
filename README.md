# WORTHTOBUY Frontend (React Router + Tailwind CSS)

Aplikasi frontend untuk WORTHTOBUY Jastip Control Center, dibangun menggunakan **React 19**, **React Router v7**, **Tailwind CSS**, **Lucide Icons**, dan **Recharts**.

---

## 🎨 Desain & Antarmuka

- **Desain Warm Luxury**: Palette warna caramel/brand, cherry red (#B8322C), dan honey yellow (#F3C32F).
- **Dashboard Eksekutif**: Ringkasan KPI omzet, profit, filter periode jastip, grafik keuangan, status order distribution.
- **Invoicing Pro**: Pembuatan invoice gabungan multi-pesanan, layout cetak A4 otomatis, format generator pesan WhatsApp langsung.
- **Track Barang & Shopping List**: Pemantauan status belanja, kept until, pencatatan harga aktual vs estimasi shopper.
- **WORTHTOBUY AI Chatbox**: Asisten bisnis interaktif berbasis context bisnis & generator Laporan Bisnis Mingguan (Weekly Report) dengan export PDF.
- **Trash Recovery**: Restore atau hapus permanen data yang terhapus secara aman.

---

## ⚙️ Panduan Menjalankan

### 1. Masuk ke folder proyek
```bash
cd worthtobuy-web
```

### 2. Instalasi dependensi
```bash
yarn install
```

### 3. Menjalankan Dev Server
```bash
yarn dev
```
Frontend akan aktif di: **http://localhost:5173** (atau port yang dialokasikan Vite).

### 4. Build Produksi
```bash
yarn build
```
